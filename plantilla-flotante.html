Carga cualquier foto · Fondo blanco automático · Efecto flotante con sombra

📷

Haz clic o arrastra una foto aquí

Acepta JPG, PNG, WEBP

Cómo funciona:
1. Carga una foto del producto — funciona mejor con fondo blanco o claro
2. Ajusta el umbral de fondo blanco para eliminar más o menos el fondo (subir = elimina más)
3. Elige formato: Cuadrado para feed · Stories para TikTok/Instagram · Banner para Marketplace
4. Descarga o copia directo al portapapeles para pegar en WhatsApp o redes

Tip: Si el fondo no desaparece del todo, primero usa remove.bg y luego carga esa imagen aquí para el efecto flotante.
